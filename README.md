# Тетрадь: Последнее имя

Атмосферная браузерная детективная игра в тёмном стиле. Это самостоятельный фан-проект, неофициально вдохновлённый жанром психологического детектива и историей о тетради с именами.

## Играть

Откройте **Settings → Pages** в настройках репозитория и включите публикацию из ветки `main`, папка `/ (root)`. После публикации GitHub Pages покажет адрес сайта.

## Управление

- Выбирай подозреваемых в досье.
- Изучай улики — нужно найти все три.
- Делай заметки: они автоматически сохраняются в браузере.
- Выбери подозреваемого и вынеси вердикт.
- Можно начать расследование заново.

## Файлы

- `index.html` — интерфейс игры.
- `style.css` — оформление.
- `game.js` — логика расследования.

## Разработка

Игра не требует сборки, сервера или установки зависимостей. Для локального запуска достаточно открыть `index.html` в браузере.
